# Amazon Food Reviews Streamlit App

This Streamlit app connects to Snowflake to display food reviews data from an Amazon dataset.

## Setup
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`.
3. Run the app: `streamlit run app.py`.

## Deployment
The app is deployed using Cortex. Once changes are pushed to the `main` branch, it is automatically deployed.
